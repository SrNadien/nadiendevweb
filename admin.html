Guardar y publicar

GitHub Pages no ejecuta PHP, así que el contenido vive en data/content.json. Hay dos formas de actualizarlo.

Opción 1 — Descargar y subir. Descargás el content.json, lo reemplazás en el repo y hacés commit. No necesitás configurar nada.
Opción 2 — Publicar directo en GitHub. Con un token propio, el panel hace el commit por vos y GitHub Pages se actualiza solo en ~1 minuto.
Creá un fine-grained token en GitHub → Settings → Developer settings, con acceso solo a este repositorio y permiso Contents: Read and write.
El token queda guardado en el localStorage de tu navegador, nunca se sube al repo ni se envía a otro servidor: el panel habla directamente con la API de GitHub. Aun así, no marques esta opción en una computadora compartida, y si el token se filtra, revocalo desde GitHub.
